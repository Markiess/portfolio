# Qikang Yan — Portfolio

Landing page for Qikang Yan, a computer science and AI student. Vite, React 18, TypeScript, Tailwind CSS 3.4, Framer Motion, and Lucide React.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Import the repository on Vercel. `vercel.json` rewrites unknown paths to `index.html` so the research and product pages work on refresh.

Project pages:

- `/about`
- `/experience`
- `/research` and `/research/llm-safety`, `/research/clickbait`
- `/products` and `/products/bitebite`

- Build command: `npm run build`
- Output directory: `dist`
